# 科技自由版10S固定规格

## 画布与分区

- 画布：1080×1920，30fps，默认10.00秒。
- 顶部A标题区：x=0–1079，y=0–577，高578px。
- 中部B轮播区：x=0–1079，y=578–1408，高831px。
- 底部C说明区：x=0–1079，y=1409–1919，高511px。
- 三个区域横向铺满。中部还必须纵向铺满，不出现模板底色、白边、空黑或圆角播放器背景。

## A标题层

- 来源标题无论在原视频顶部还是紧贴轮播上方，都归入A层并完整移动到成片顶部。
- 默认沿用来源标题的信息和分组；不得遗漏主体、数字、时间、变化、转折和结论。
- 可保留2至4行，不为凑行数增加内容。用户明确要求原创改写时才改写。
- 两行参考中心：y=355、470。
- 三行参考中心：y=310、405、505。
- 四行参考中心：y=230、325、415、510。
- 主要事实行使用微软雅黑粗斜体、白色、青蓝描边和轻阴影。
- 最终结论块统一亮黄色、深金色描边，字号在对应基础字号上放大20%。
- 黄色结论过宽时只调 `fscx`，保持放大后的字高。
- 标题后不放黑色文字框，不放Logo、账号名、水印或角标。

## B轮播层

- 只允许出现来源里的图片、视频、网页、帖子、图表、文档或产品界面。
- 来源画面自身的文字属于展示内容，可以保留；模板不得在中部新增标题、说明或字幕。
- 先找出每个镜头的有效主体边界，再裁掉来源A标题、C说明、播放器控件、水印、边框和无内容区域。
- 中部使用等比例cover覆盖1080×831，不直接拉伸界面文字。
- 禁止contain、缩成95%、四边留距、白边、黑边和模糊副本补边。
- 黑色帖子或深色网页的有效背景可以保留；顶部、底部或两侧没有有效内容的纯黑区域必须裁掉。
- 镜头切换后主体位置变化时，按来源时间轴拆成多个裁切段，再拼接并统一变速到10秒。
- 中部上边框使用细洋红线，下边框使用细蓝紫线，紧贴区域边缘且不得挡字。

## C底部说明

- 固定五行，所有文字从首帧显示到结尾。
- 图标中心x=105，标签起点x=170，正文建议起点x=410；短标签可使用x=365。
- 五行中心y=1490、1555、1620、1685、1750，行距65px。
- 图标约42px；标签与正文51px。
- 图标为小型霓虹线性符号，标签橙粉色粗体，正文白色中粗体。
- 五条分别概括：发生什么、关键机制、核心数据、使用方式或扩散、风险或结论。
- 超宽时先压缩措辞，再轻度调小横向比例；不得降低51px字高或越过右侧安全区。

## 背景与音频

- 公开版使用渲染器代码绘制深蓝背景和紫蓝装饰线，不需要图片资产。
- 顶部和底部为100%不透明背景，不能透出来源文字。
- 使用用户提供的有权使用的音频；公开包不附带私人固定配音。不混入来源音频；没有音频时显式选择静音。
- 输入音频取前10秒，短音频补静音，不改变语速；非静音音轨峰值目标低于-1dBFS。

## 输出与交付

- H.264、yuv420p、30fps、AAC 44.1kHz双声道、faststart。
- 参考视频不足10秒时均匀放慢，超过10秒时均匀加速；禁止黑帧和无意义重复。
- 每次一次性交付MP4、画面标题、底部五条、视频号发布标题、发布文案和8至10个话题。
- 主动把MP4发送到Codex右侧面板，并给出可点击链接与Windows完整绝对路径。
