# 配置

JSON使用UTF-8。所有时间是输入视频的秒数，坐标是原始像素（不是成片像素）。

- title：2–4个字符串，末行自动黄色93.6px，其余78px。
- title_scale：可选，与title等长，40–100的横向百分比；默认100。
- rows：5组[label, body]，标签和正文51px；标签建议2字，正文建议不超过12字。
- segments：按时间排序、不重叠的片段列表，每段至少0.1秒。
- start/end：起止秒数；不得超出视频时长。
- x/y/width/height：整数像素，矩形必须位于视频内。允许奇数高度。
- 标题和底部不能包含换行、花括号或反斜杠，防止ASS标签注入。
- 素材裁切后等比cover；所有片段拼接后统一变速到10秒。

人工检查：每次切镜都核对有效主体，避开原标题、底部解释、播放器边框和空黑。不同布局使用不同坐标。过长文案不会自动缩字，需在预览后修订。
